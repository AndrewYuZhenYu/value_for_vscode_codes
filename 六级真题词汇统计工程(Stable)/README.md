# CET-6 真题高频词自动化工具包

一套用于自动采集 CET-6（大学英语六级）历年真题文本、清洗网页噪点并统计全量词频的 Python 自动化工具，最终输出一份按出现频率排序的 Excel 高频词汇表。

项目通过浏览器自动化与剪贴板模拟完成真题抓取，再经文本清洗与词频统计两个离线步骤，将原始网页内容转化为可直接用于词汇复习的结构化数据。

---

## 项目简介

本项目面向需要基于真实六级真题进行高频词复习的使用者。相比传统词书按字母或主题平均分配词汇，本工具直接从历年真题原文中统计词频，使复习重点更贴近实际考试出现频率。

整个流程分为三个阶段，必须按顺序执行：

```text
真题抓取  →  文本清洗  →  词频统计  →  Excel 词汇表
```

三个阶段的产物分别为：

| 阶段     | 输入                   | 输出                                  |
| -------- | ---------------------- | ------------------------------------- |
| 真题抓取 | 真题目录页 URL         | `cet6_zhenti_data/` 原始文本          |
| 文本清洗 | `cet6_zhenti_data/`    | `cet6_zhenti_cleaned/` 纯净文本       |
| 词频统计 | `cet6_zhenti_cleaned/` | `cet6_full_vocabulary_frequency.xlsx` |

---

## 主要功能

- **真题自动抓取**：通过 Selenium 连接已开启调试端口的 Chrome，识别目录页中的真题链接，逐页访问并保存文本。
- **三段式拼图抓取**：对每个真题页面分别抓取顶部、中段、尾部三段文本，规避长页面一次性复制不完整的问题。
- **智能去重合并**：对三段文本按行去重，过滤网页公共噪点（导航、版权、菜单等），保留原始排版。
- **文本清洗**：逐行去除页码、时间戳、固定噪点行等无关内容，兼容不同操作系统的换行符。
- **全量词频统计**：基于清洗后的全部文本统计英文单词出现次数，过滤题干结构词与基础停用词，按频次降序导出 Excel。

## 快速开始

### 环境要求

- Python 3.8 及以上
- Google Chrome 浏览器
- 操作系统：脚本中使用了 `ctrl` 组合键与 `os.name` 判断，已在 Windows 与 macOS 上考虑兼容；未在其他平台验证。

### 安装依赖

```bash
pip install selenium webdriver-manager pyautogui pyperclip pandas openpyxl
```

各依赖作用如下：

| 库                  | 作用                       |
| ------------------- | -------------------------- |
| `selenium`          | 控制浏览器，实现网页自动化 |
| `webdriver-manager` | 自动管理 ChromeDriver      |
| `pyautogui`         | 模拟键盘与鼠标操作         |
| `pyperclip`         | 读写剪贴板内容             |
| `pandas`            | 构建并导出词频数据         |
| `openpyxl`          | 写入 Excel 文件            |

### 运行前准备

抓取阶段依赖真实浏览器操作与剪贴板，运行前需满足：

1. 已安装 Google Chrome。
2. Chrome 以远程调试模式启动，监听 `127.0.0.1:9222`。

   Windows 示例：

   ```bash
   chrome.exe --remote-debugging-port=9222 --user-data-dir="C:\chrome_debug"
   ```

   macOS 示例：

   ```bash
   /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir="/tmp/chrome_debug"
   ```

3. 抓取期间**不要移动鼠标、不要按键盘、不要切换窗口、不要让电脑休眠**。

### 执行顺序

三个脚本必须按以下顺序运行：

```bash
python 批量全选复制粘贴自动化程序.py
python wash_data.py
python analyze_frequency.py
```

## 使用方法

### 步骤一：真题抓取

文件：`批量全选复制粘贴自动化程序.py`

脚本通过 Selenium 附加到已打开的 Chrome 调试实例，访问目录页 `https://zhenti.burningvocabulary.cn/cet6`，提取其中包含 `/cet6/` 的链接，逐个打开并执行三段式复制。

对每个真题页面，脚本依次执行：

1. 窗口聚焦后全选复制，抓取顶部文本；
2. 按 4 次 `PageDown` 后全选复制，抓取中段文本；
3. 按 `Ctrl+End` 直达底部后全选复制，抓取尾部文本；
4. 回弹到页面顶部；
5. 对三段文本去重合并，写入文件。

输出目录：

```text
cet6_zhenti_data/
```

每个真题对应一个 `.txt` 文件，文件名由 URL 路径生成，并替换非法字符。

抓取完成后，脚本会对合并结果做长度检查：若少于 3000 字符，会提示可能未聚焦成功，但仍会继续处理后续页面。

运行命令：

```bash
python 批量全选复制粘贴自动化程序.py
```

### 步骤二：文本清洗

文件：`wash_data.py`

脚本读取 `cet6_zhenti_data/` 中的全部 `.txt` 文件，逐行清洗后写入 `cet6_zhenti_cleaned/`。

清洗规则包括：

- 跳过空行；
- 跳过与固定噪点完全匹配的行（如 `升级付费版`、`自动缩放`、`player settings`、`安装app`、`生词本`）；
- 跳过形如 `第 N 页` 的行；
- 跳过单独的小写字母 `i`；
- 去除行内形如 `12:34` 的时间戳；
- 将连续 3 个以上换行压缩为 2 个。

若源文件非空但清洗后变为空，脚本会给出警告，便于排查是否误杀内容。

运行命令：

```bash
python wash_data.py
```

### 步骤三：词频统计

文件：`analyze_frequency.py`

脚本读取 `cet6_zhenti_cleaned/` 中的全部 `.txt` 文件，统计英文单词出现次数，并导出 Excel。

处理逻辑：

1. 将全文转为小写；
2. 用正则 `\b[a-z-]+\b` 提取单词；
3. 跳过长度小于等于 1 的词；
4. 跳过停用词与题干结构词；
5. 统计剩余词频并降序排序；
6. 导出为 `cet6_full_vocabulary_frequency.xlsx`。

运行命令：

```bash
python analyze_frequency.py
```

输出 Excel 包含三列：

| 列名                       | 说明                       |
| -------------------------- | -------------------------- |
| 大数据排名 (Rank)          | 按频次降序的排名           |
| 核心词汇 (Word)            | 单词                       |
| 全站出现总频次 (Frequency) | 在全部清洗文本中的出现次数 |

## 核心模块

### `批量全选复制粘贴自动化程序.py`

职责：完成真题页面的自动访问与文本采集。

| 函数                                                 | 说明                                                |
| ---------------------------------------------------- | --------------------------------------------------- |
| `get_all_zhenti_urls(driver, list_url)`              | 打开目录页，收集所有含 `/cet6/` 的链接并去重        |
| `rpa_copy_action()`                                  | 清空剪贴板后执行 `Ctrl+A`、`Ctrl+C`，返回剪贴板文本 |
| `merge_chunks(chunks)`                               | 按行去重合并三段文本，过滤网页公共噪点              |
| `scrape_single_page_puzzle(driver, url, output_dir)` | 对单个真题页面执行三段式抓取、合并与落盘            |
| `main()`                                             | 初始化 Chrome 选项、连接调试端口、遍历全部链接      |

关键点：

- 通过 `debuggerAddress` 附加到已运行的 Chrome，而非新开浏览器实例。
- 抓取依赖真实键盘与剪贴板，因此脚本运行期间会占用用户输入。
- 合并阶段对每一行做一次英文噪点检测，命中 `home`、`about`、`copyright`、`menu`、`login`、`vocabulary`、`burning` 等关键词的行会被丢弃。

### `wash_data.py`

职责：对抓取文本做行级清洗。

| 函数                           | 说明                                 |
| ------------------------------ | ------------------------------------ |
| `clean_text_content(raw_text)` | 核心清洗逻辑，返回清洗后的文本       |
| `main()`                       | 遍历输入目录，逐个清洗并写入输出目录 |

关键点：

- 使用 `splitlines()` 兼容不同平台的换行符。
- 噪点匹配分两类：整行精确匹配固定噪点集合，正则匹配页码行。
- 清洗后会压缩多余空行，并在源文件非空而结果为空时输出警告。

### `analyze_frequency.py`

职责：统计清洗后文本的全量词频并导出。

| 函数                       | 说明                                 |
| -------------------------- | ------------------------------------ |
| `load_custom_stopwords()`  | 返回题干结构词与基础英语停用词的并集 |
| `analyze_cet6_full_data()` | 遍历输入目录、统计词频、导出 Excel   |

关键点：

- 停用词集合包含两部分：六级题干常见结构词（如 `section`、`directions`、`passage`）与基础英语停用词（如 `the`、`and`、`of`）。
- 单字母词被直接跳过。
- 统计结果不设数量上限，导出全部词汇。

## 关键设计与实现

- **三段式抓取**：长页面一次性 `Ctrl+A` 可能因渲染范围限制而漏掉中后段内容。脚本通过 `PageDown` 与 `Ctrl+End` 主动滚动，唤醒不同区域的 DOM，再分段复制后合并，以降低漏抓概率。
- **按行去重**：三段复制内容存在重叠，采用按行去重而非按字符去重，既消除重复又不破坏原有排版。
- **剪贴板作为数据通道**：复制结果通过 `pyperclip` 读取，而非从 DOM 直接提取文本。这使脚本能获取浏览器渲染后的可见文本，但代价是依赖窗口焦点与人工不干预。
- **停用词双层过滤**：题干结构词与基础停用词分开维护，便于后续按需调整。前者针对六级试卷的固定表述，后者覆盖通用高频功能词。
- **全量导出**：统计阶段不对词汇数量设限，保留完整词盘，由使用者自行决定学习范围。
- **路径硬编码**：清洗与统计脚本使用绝对路径，便于在固定开发环境中直接运行，但迁移时需手动修改。

## 已知限制

- 抓取阶段依赖图形界面、窗口焦点与剪贴板，无法在无头环境中运行。
- 抓取期间任何人工鼠标或键盘操作都可能干扰结果。
- 页面结构与目标站点改版可能导致链接识别或复制逻辑失效。
- 清洗规则基于当前网页噪点特征，站点变化后可能需要更新噪点集合。
- 停用词表为静态维护，未覆盖所有可能的题干结构词。
- 清洗与统计脚本的输入、输出路径为硬编码绝对路径，迁移成本较高。
- 项目当前没有自动化测试。

## 常见问题

### 抓取结果为空或文本过少

可能原因：

- 运行期间移动了鼠标或键盘；
- 浏览器弹窗抢占焦点；
- 页面加载未完成；
- 电脑进入休眠。

处理方式：重新运行抓取脚本，全程保持手离开键鼠，保持网络稳定，不切换窗口。

### 提示找不到文件夹

如出现 `FileNotFoundError`，通常是因为前一阶段未成功运行。请按顺序确认：

```text
抓取程序 → cet6_zhenti_data 是否生成
清洗程序 → cet6_zhenti_cleaned 是否生成
统计程序 → Excel 是否生成
```

同时检查 `wash_data.py` 与 `analyze_frequency.py` 中的路径是否与当前机器一致。

### Excel 无法生成

可能缺少依赖。重新安装后重试：

```bash
pip install pandas openpyxl
python analyze_frequency.py
```

### 抓取时提示无法连接 Chrome

确认 Chrome 已以远程调试模式启动，且端口为 `9222`。若端口被占用或 Chrome 未启动，Selenium 将无法附加。

## 使用建议

- 优先学习频次最高的核心词，再逐步扩展。
- 结合真题原句理解词义，避免脱离语境记忆。
- 有新真题数据时可重新运行全流程，覆盖旧结果。
- 可将 Excel 导入 Anki 等记忆软件进行复习。
