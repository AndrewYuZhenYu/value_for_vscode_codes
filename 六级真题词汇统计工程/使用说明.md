# CET-6 真题高频词自动化工具包教程

## 简介

本工具用于自动分析 CET-6（大学英语六级）历年真题文本，通过自动化程序完成真题数据采集、文本清理以及词频统计，最终生成一份可用于背诵和复习的高频词汇表。

整个流程分为三个阶段：

1. **抓取真题数据**：自动从网页中获取历年六级真题文本。
2. **文本清洗处理**：去除网页中的无关内容，例如页码、时间信息、格式符号等，使文本更加适合分析。
3. **词频统计分析**：统计有效词汇出现次数，并按照频率排序，生成 Excel 词汇表。

通过这一流程，可以快速从大量真题中提取六级考试中的高频核心词汇，提高词汇复习的针对性。

---

# 1. 环境准备

## 安装 Python 环境

运行本工具需要 Python 环境。

建议使用 Python 3.8 及以上版本，以保证第三方库兼容性。

安装完成后，在终端或命令提示符中执行以下命令安装所需依赖：

```bash
pip install selenium webdriver-manager pyautogui pyperclip pandas openpyxl
```

这些库的主要作用如下：

| 库                | 作用                               |
| ----------------- | ---------------------------------- |
| selenium          | 自动控制浏览器，实现网页自动化操作 |
| webdriver-manager | 自动管理 Chrome 浏览器驱动         |
| pyautogui         | 模拟鼠标、键盘操作                 |
| pyperclip         | 读取和操作剪贴板内容               |
| pandas            | 数据处理和分析                     |
| openpyxl          | 生成和操作 Excel 文件              |

---

## ⚠️ 运行前的重要准备

在正式运行程序之前，请确认以下条件：

1. 已安装 **Google Chrome 浏览器**。
2. 浏览器版本正常，能够被 Selenium 调用。
3. 运行抓取程序时，请保持电脑处于正常工作状态。

特别注意：

由于第一步抓取程序会模拟真实用户操作，包括自动点击、复制、翻页等，因此：

- **运行期间不要移动鼠标。**
- **不要按键盘。**
- **不要切换窗口。**
- **不要让电脑进入睡眠状态。**

任何人为操作都可能干扰自动化流程，导致数据抓取失败。

---

# 2. 工具运行流程

请确保三个 Python 文件位于同一个文件夹内，并严格按照以下顺序执行：

```
抓取真题
    ↓
清洗文本
    ↓
统计词频
    ↓
生成 Excel 词汇表
```

顺序不能调整。

因为后面的程序依赖前一步产生的数据文件，如果跳过某一步，可能会出现文件不存在或者数据为空的问题。

---

# 步骤一：数据抓取

文件：

```
批量全选复制粘贴自动化程序.py
```

## 功能介绍

该程序负责自动访问真题页面，并通过模拟操作完成：

- 页面翻页；
- 全选文本；
- 复制内容；
- 保存文本数据。

抓取后的原始数据会保存到：

```
cet6_zhenti_data
```

文件夹中。

---

## 运行命令

```bash
python 批量全选复制粘贴自动化程序.py
```

---

## 注意事项

运行过程中程序会控制鼠标和键盘，因此必须：

- 保持当前窗口处于前台；
- 保证网页加载完成；
- 不进行其他电脑操作。

如果过程中出现弹窗、页面卡顿或者电脑休眠，可能导致复制内容不完整。

---

# 步骤二：文本清洗

文件：

```
wash_data.py
```

## 功能介绍

网页中的原始文本通常包含大量无关信息，例如：

- 页码；
- 时间标记；
- 网页格式残留；
- 多余空格；
- 特殊符号。

这些内容会影响后续词频统计，因此需要先进行清理。

该程序会读取：

```
cet6_zhenti_data
```

中的原始文本，并生成处理后的纯净文本：

```
cet6_zhenti_cleaned
```

---

## 运行命令

```bash
python wash_data.py
```

---

## 清洗后的效果

例如：

原始文本：

```
Reading Test
2024-06-15
The development of technology...
Page 1
```

清洗后：

```
The development of technology...
```

这样可以提高后续词频分析的准确性。

---

# 步骤三：词频统计

文件：

```
analyze_frequency.py
```

## 功能介绍

该程序负责对清洗后的文本进行分析。

主要处理过程包括：

1. 分割文本中的单词；
2. 统计每个单词出现次数；
3. 删除基础语法词和无意义词；
4. 根据出现频率进行排序；
5. 导出 Excel 文件。

最终生成：

```
cet6_full_vocabulary_frequency.xlsx
```

该文件就是最终的六级真题高频词库。

---

## 运行命令

```bash
python analyze_frequency.py
```

---

## Excel 文件内容

生成的 Excel 通常包含：

- 单词；
- 出现次数；
- 排名。

可以根据出现频率优先学习高频词，提高复习效率。

# 3. 常见问题

## 1. 抓取结果为空或文本数量很少

可能原因：

- 运行过程中移动了鼠标或键盘；
- 浏览器弹出窗口影响操作；
- 页面加载失败；
- 电脑进入休眠状态。

解决方法：

重新运行抓取程序，并确保：

- 手离开键盘鼠标；
- 保持网络稳定；
- 不切换其他程序。

---

## 2. 提示找不到文件夹

例如：

```
FileNotFoundError
```

通常原因：

前一步程序没有成功运行。

检查流程：

```
抓取程序
    ↓
cet6_zhenti_data 是否生成

清洗程序
    ↓
cet6_zhenti_cleaned 是否生成

统计程序
    ↓
生成 Excel
```

必须按照顺序执行。

---

## 3. Excel 文件无法生成

可能原因：

缺少 Python 依赖库。

重新安装：

```bash
pip install pandas openpyxl
```

然后再次运行：

```bash
python analyze_frequency.py
```

---

# 4. 使用建议

生成高频词库后，建议不要简单按照字母顺序背诵，而是按照出现频率进行学习。

推荐方法：

1. 优先学习出现次数最高的核心词；
2. 结合真题原句理解词义；
3. 定期重新统计新的真题数据；
4. 将 Excel 文件导入 Anki 等记忆软件进行复习。

通过自动化统计，可以避免传统词书中“平均分配词汇”的问题，让复习更加贴近真实考试需求。
