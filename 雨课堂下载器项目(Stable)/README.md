# 雨课堂课件下载器 (Yuketang PPT Downloader)

一个基于 **Playwright** 浏览器自动化的雨课堂课件下载工具，能够将雨课堂网页端的 PPT 课件逐页截图，并自动合成为 PDF 文件，方便离线查看、打印或归档。

## 一、面向用户

### 1.1 程序能做什么

雨课堂网页版通常会限制课件下载，只能在线一页页翻看。本程序通过模拟人工操作浏览器，自动完成以下流程：

1. 打开你提供的雨课堂课件页面；
2. 复用你首次扫码登录后的会话（不用每次重新登录）；
3. 自动逐页点击左侧缩略图翻页；
4. 对每一页课件区域截图（同时**自动移除页面右下角黑色悬浮按钮**，避免遮挡课件内容）；
5. 将所有截图按顺序合成为一个 PDF 文件；
6. 自动清理过程中的临时图片和文件夹。

最终你会得到一个干净、无遮挡、顺序正确的 PDF 课件。

### 1.2 环境准备

**系统要求：**

- Windows / macOS / Linux 均可
- 已安装 Python 3.8 及以上版本

**安装依赖：**

```bash
pip install playwright img2pdf
playwright install chromium
```

> `playwright install chromium` 会下载 Chromium 浏览器内核，首次安装耗时较长，请耐心等待。

### 1.3 使用方法

**第一步：运行程序**

```bash
python 雨课堂下载器.py
```

**第二步：按提示输入三项配置**

| 提示                     | 说明                                       | 示例                              |
| ------------------------ | ------------------------------------------ | --------------------------------- |
| 请输入课件的网址         | 从浏览器地址栏复制雨课堂课件页面的完整 URL | `https://yuketang.cn/lesson/xxxx` |
| 请输入截图保存文件夹名称 | 临时存放截图的目录，直接回车使用默认值     | 回车即可                          |
| 请输入生成的 PDF 文件名  | 最终 PDF 的名称，直接回车使用默认值        | 回车即可                          |

**第三步：扫码登录（仅首次需要）**

程序会弹出 Chromium 浏览器窗口。如果未登录，请使用微信扫码登录；登录状态会被保存在 `./yuketang_login_cache` 目录中，**下次运行无需再次扫码**。

**第四步：等待自动执行**

程序检测到课件后会显示总页数，然后逐页截图。每页停留约 2 秒以确保文字、公式、图片渲染完成。全部完成后自动合成 PDF 并清理临时文件。

**输出结果：**

- `下载课件.pdf`（或你自定义的文件名）
- 控制台会打印每页进度和最终结果

### 1.4 常见问题

**Q1：提示"未能检测到课件页面"怎么办？**

- 检查网址是否是正确的课件页面（不是课程列表页）；
- 确认已成功登录雨课堂；
- 若页面结构有更新，可能需要同步更新脚本中的选择器。

**Q2：截图里有黑色按钮遮挡内容？**

- 本程序已内置移除逻辑，针对 `.layout_right_switch` 元素。如果雨课堂更新了页面结构导致遮挡再次出现，请参考[开发者章节](#24-关键代码解析)更新 JS 选择器。

**Q3：某些页面内容缺失 / 公式没渲染出来？**

- 可适当增大 `time.sleep(2.0)` 的等待时间（网络慢或页面重时尤其有效）。

**Q4：登录状态会过期吗？**

- 会。若某次运行要求重新扫码，属于正常现象。删除 `./yuketang_login_cache` 目录可强制重新登录。

**Q5：合成的 PDF 太大怎么办？**

- 可在合成后使用其他工具压缩，或修改脚本降低截图分辨率（见开发者章节）。

## 二、面向开发者

### 2.1 技术栈

| 组件                      | 作用                                   |
| ------------------------- | -------------------------------------- |
| **Python 3**              | 主语言                                 |
| **Playwright (sync API)** | 浏览器自动化、页面导航、元素定位、截图 |
| **img2pdf**               | 将 PNG 图片无损合成为 PDF              |
| **os / time / shutil**    | 路径管理、等待、目录清理               |

选型理由：

- Playwright 相比 Selenium 对现代前端（Vue/React 单页应用）支持更好，能可靠地 `wait_for_selector` 和 `scroll_into_view`；
- `launch_persistent_context` 提供持久化用户数据目录，天然支持"一次登录，多次复用"；
- `img2pdf` 直接封装图片为 PDF，无需重新编码，速度快、无损。

### 2.2 整体架构

程序是**单文件、线性流程**的脚本，没有引入类或模块拆分，整体分为四层：

```
┌─────────────────────────────────────────────┐
│  1. 交互层  input() 收集 URL / 目录 / PDF 名   │
├─────────────────────────────────────────────┤
│  2. 浏览器层 Playwright 启动持久化上下文       │
│     - 加载页面、等待课件容器出现               │
├─────────────────────────────────────────────┤
│  3. 采集层  遍历缩略图 → 点击翻页 → 注入 JS   │
│     移除遮挡 → 定位 .slide_layer 截图          │
├─────────────────────────────────────────────┤
│  4. 后处理层 img2pdf 合成 PDF → shutil 清理   │
└─────────────────────────────────────────────┘
```

### 2.3 核心实现原理

**① 持久化登录（免重复扫码）**

```python
context = p.chromium.launch_persistent_context(
    user_data_dir=USER_DATA_DIR,   # ./yuketang_login_cache
    headless=False,
    viewport={'width': 1920, 'height': 1080},
    args=['--force-device-scale-factor=1']
)
```

- `user_data_dir` 让 Chromium 把 Cookie、LocalStorage 等写入本地目录，实现跨会话登录保持；
- `headless=False` 必须为 False，因为需要人工扫码；
- `--force-device-scale-factor=1` 固定设备像素比，保证截图分辨率稳定可控；
- `viewport` 固定为 1920×1080，避免不同屏幕尺寸导致的布局差异。

**② 等待课件加载**

```python
page.wait_for_selector(".thumbImg-container", timeout=60000)
thumbnails = page.locator(".thumbImg-container")
total_pages = thumbnails.count()
```

- 用左侧缩略图容器 `.thumbImg-container` 作为"课件已就绪"的信号；
- 通过 `count()` 得到总页数，作为后续循环的边界。

**③ 逐页翻页 + 截图**

```python
for i in range(total_pages):
    thumb = thumbnails.nth(i)
    thumb.scroll_into_view_if_needed()  # 确保缩略图在视口内可点击
    thumb.click()                       # 触发翻页
    time.sleep(2.0)                     # 等待内容渲染
    page.evaluate(remove_btn_js)        # 注入 JS 删除遮挡元素
    page.locator(".slide_layer").first.screenshot(path=img_path)
```

关键点：

- **`scroll_into_view_if_needed`**：缩略图列表可能很长，不滚动到可视区直接点击会失败；
- **`time.sleep(2.0)`**：雨课堂课件包含大量公式、图片，是异步渲染的，必须给足渲染时间；
- **`.slide_layer`**：这是课件主内容图层，只截它而不是整页，避免把工具栏、缩略图栏一起截进来。

**④ 动态移除遮挡元素**

```javascript
const blackBtn = document.querySelector(
  "#app > div.viewContainer > ... > div.layout_right_switch",
);
if (blackBtn) {
  blackBtn.remove();
}
```

- 雨课堂右下角有一个黑色悬浮按钮（切换布局用），会遮挡课件内容；
- 该元素在每次翻页时会被前端框架重新挂载，因此**必须在每次截图前执行一次移除**，否则会被重绘回来；
- 使用父级包装器 `.layout_right_switch` 整体删除，比只隐藏按钮本身更彻底。

**⑤ 合成 PDF 与清理**

```python
with open(OUTPUT_PDF, "wb") as f:
    f.write(img2pdf.convert(image_paths))
shutil.rmtree(SAVE_DIR)
```

- `img2pdf.convert` 接收图片路径列表，按列表顺序输出 PDF，因此**截图顺序即 PDF 页序**；
- `image_paths` 只追加成功截图，异常页会被 `continue` 跳过，不会污染 PDF；
- 合成成功后递归删除临时目录，保持工作区干净。

### 2.4 关键代码解析

| 变量 / 参数                            | 作用               | 调优建议                         |
| -------------------------------------- | ------------------ | -------------------------------- |
| `USER_DATA_DIR`                        | 登录缓存目录       | 想强制重新登录就删掉它           |
| `viewport`                             | 浏览器视口尺寸     | 更大可提高截图清晰度，但文件更大 |
| `--force-device-scale-factor=1`        | 固定缩放比         | 改为 `2` 可得到 2 倍分辨率截图   |
| `wait_for_selector` 的 `timeout=60000` | 等待登录+加载      | 网络差可再调大                   |
| `time.sleep(2.0)`                      | 单页渲染等待       | 慢网/重页建议 3~5 秒             |
| `.thumbImg-container`                  | 缩略图选择器       | 页面改版时需同步更新             |
| `.slide_layer`                         | 课件内容图层选择器 | 同上                             |
| `remove_btn_js` 中的绝对路径           | 定位遮挡按钮       | 页面 DOM 变动时需更新            |

### 2.6 可扩展方向

1. **进度与断点续传**：将已截图的页码记录到 `.json`，异常中断后可跳过已完成页；
2. **智能等待**：用 `page.wait_for_function` 检测页面渲染完成的标志，替代固定 `sleep`；
3. **选择器配置化**：把 `.thumbImg-container`、`.slide_layer`、遮挡按钮路径抽到配置文件，便于应对页面改版；
4. **多课件批量下载**：读取 CSV/TXT 中的 URL 列表循环执行；
5. **OCR 与文字层**：对截图做 OCR 后写入 PDF 的可搜索文字层（如结合 `pytesseract` + `pypdf`）；
6. **图片压缩**：在合成前用 Pillow 压缩 PNG，减小 PDF 体积；
7. **异常重试**：对截图失败的页面自动重试 N 次，提升鲁棒性；
8. **异步化**：改用 Playwright async API，在等待渲染时并行处理已截图片的压缩。
